# JavaScript Exercises

This repository contains multiple JavaScript exercises, each located on its own branch. The exercises used to practice fundamental JavaScript concepts by running the code directly in your browser.
---

## 📂 Repository Structure
- **main** — Base branch (contains readme).  
- **exercise branches** — One exercise per branch. The commit message for the .js file indicates the topic ( e.g loops, arrays, functions)
---

## 🛠 Requirements
Before running any exercise, you'll need the following installed:  
- **VS Code** with the **Live Server** extension installed

---

## 🚀 How to Run an Exercise
1. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd <repo-folder>
   ```

2. **Switch to the exercise branch**
   ```bash
   git fetch origin
   git checkout exercise-1
   ```
   Replace exercise-1 with whatever branch you want to run.

3. **Run the server**
- For exercises 1-6, create an 'index.html' and insert the corresponding script.js on the branch
   ```bash
   <body>
    <script src="everything.js"></script>
   </body>
   ```

- Right click on the html file and select 'open with live server'

- This will open the page in your default browser.

- Open the browser's Developer Tools (usually by pressing F12 or Ctrl+Shift+I) and navigate to the Console tab to see the output.
